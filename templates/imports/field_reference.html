CSV/XLSX columns: required fields and taxonomy tagging

Single-language rows: include question_number, question_text, option_a, option_b, option_c, and option_d. A valid correct_answer (A/B/C/D) is required before confirmation. source_question_number can replace a missing question_number header.

Recommended tagging: supply an existing topic_code. The importer resolves its Subject, Part, Module, optional Sub-module and Chapter automatically. Optional subject_code, part_code, module_code, submodule_code, and chapter_code must agree with that path. sub_module_code is an accepted alias. Codes ignore case and outer whitespace.

Optional taxonomy names: subject, part, module, submodule (or sub_module), chapter, topic. Named missing child nodes may be proposed in preview; Subjects must already exist. A new Sub-module requires a Module. Extra tags use additional_topic_codes, separated by semicolon, comma or pipe, within the same Subject. Without a primary Topic, ancestor columns alone do not attach a question tag.

Language: optional language uses the row value, batch default, or English/Bengali inference. For one bilingual row use complete question_text_en, option_a_en through option_d_en and/or the equivalent _bn block. Each available language block must be complete; explanation_en/explanation_bn are optional. Both editions share one answer and one set of tags.

Other optional columns: explanation, difficulty_level, exam_categories, previous_year_tags, source_code, source_document, source_publisher, source_page, source_question_number, review_status, verification_notes, comments, created_date, updated_date, updated_by, handwritten_mark_unverified, needs_review, source_row. A source page requires a source code or document. A new source code requires a document on at least one row. Review/date/user columns are audit metadata, not approval or system values.

Form selection: General Questions needs selected Exams; Previous Year needs an Exam and Year. Row exam_categories resolves existing Exams only when row mapping is enabled. The form's paper Part/Session are paper identity; CSV part is taxonomy. Files use UTF-8 CSV or plain-value XLSX. Duplicate aliases, unknown headers and conflicting paths are rejected.
